# Netra Ecosystem (app)

One app to see, download, install and update all Netra apps by Prayagi Team. Part of the Netra Ecosystem family: https://prayagi-store-and-services.github.io/netra-eco/

Releases: https://github.com/prayagi-store-and-services/netra-eco-app/releases

See SECURITY.md for what the app does and does not do.

## What's new in v1.2.42

Human Safety download, update and install controls are paused with the heat/battery advisory. Saved Human Safety installers show the warning and a Delete control instead of Install. Other apps remain available. This is not a heat fix and does not revoke old Eco clients or external APKs.
